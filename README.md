# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？
リモートリポジトリ→チーム開発や個人開発においてネット上でソースコードを管理するリポジトリ。
ローカルリポジトリ→自分のPC上にファイルやディレクトリを配置して開発を行うリポジトリ。


## プッシュとマージの違いは何でしょうか？
push→ローカル上でのブランチの状態をリモートにアップすること。
merge→ブランチの状態を他ブランチに統合すること。
pushがローカルからリモート間での作業に対してmergeはリポジトリ内のブランチ間での作業

## コミットとプッシュの違い
ローカル環境においてcommitがステージングされた修正箇所の保存に対して
commit内容をリモート環境に反映させるのがpush


## コミットのメッセージはどのように書いてあげるのが最適でしょうか？
チームメンバーや自分が見返した時にコミットメッセージから修正の内容を判断できるよう、
具体的な改修内容と範囲などを記載する。


## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？
ローカルでのmergeは他者のレビューを挟まずに自分の個人環境で自分でmergeする。
プルリクエストはリモート上で作成するため、チーム開発では他者目線でのレビューを行ってからmergeできる。
他者のレビューの有無とどのリポジトリでの操作かの違いがある。


## コンフリクトを起こしてしまった場合、どう対処すべきですか？
作業担当者同士で審議し、どちらのコードを採用するのか、それともどちらのコードも取り入れるのかを話し合って修正する。
